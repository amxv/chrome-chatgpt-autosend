ChatGPT Auto-Send

Your extension has generated a private, random secret for this browser profile. Set up your site-search shortcut once, then prompts send automatically without any approval popups.

Generating your setup URL…

  1. Open chrome://settings/searchEngines (or the equivalent settings page in Dia).
  2. Under Site search, add or edit ChatGPT with shortcut c.
  3. Paste the URL above into URL with %s in place of query.

Now type c + Space, your prompt, and Enter. The extension opens the Chat / Work selector, selects Chat, and only sends once Chat mode is confirmed. Existing shortcuts pointing at the site root also work.

Keep this URL private. It is stored in your browser settings and contains a secret, although the extension also independently checks the navigation source.
